# ブランドコンセプト

## ビジョン

転んでも立ち上がる力を身につけ、
自分の時間を創り、大切なものを守る。

---

## コンセプト

Matsunami Lab は、
初学者から中級者を対象としたデジタルラーニングプラットフォームです。

Power Platform を中心に、
生成AIやデジタルツールの活用方法を、
やさしく、わかりやすく、実践的に学べるコンテンツを提供します。

知識を得るだけでなく、
一歩ずつ成長し、自ら考え行動できる力を育むことを目指します。
